# 💫 About Me:

My role sits at the intersection of quality engineering, data validation, and secure systems.<br><br>I’m interested in collaborating on AI-driven test automation, data-centric validation pipelines, and computer vision or generative AI applications where models actually ship, not just train.<br><br>Currently expanding my skill set in generative AI, prompt engineering, and AI agents, with hands-on learning through Google Cloud and LinkedIn Learning certifications.
